releases**; the source code is not published here.

All versions and release notes: [Releases](https://github.com/nohuman-team/releases/releases).
Not sure which Mac you have? Apple menu → About This Mac: "Apple M…" is Apple silicon, "Intel" is Intel.

**macOS:** open the `.dmg`, drag noHuman Team into Applications and open it from there. The app is signed and checked by Apple, and from 3.2.3 on it updates itself.

The app is free for 6 months. Claim a key at https://www.nohuman.team/claim?campaign=FREE
and paste it into the setup wizard together with the same email.

Connect a supported subscription or provider. Choices include Claude Pro/Max,
ChatGPT Plus/Pro, Gemini, GitHub Copilot, OpenRouter, API-key services and local
Ollama models. The app installs Claude Code and OpenCode when your provider needs
them. You do not need a terminal or Node.js.

Already installed? Your team, memory and workspace are kept when you install a new version.
